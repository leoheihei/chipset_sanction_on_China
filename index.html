关于本项目

本仓库以 GitHub Pages 方式发布每周定期生成的《美国对华芯片制裁周报》。统计范围覆盖：对华芯片出口管制新规（先进计算芯片、半导体设备、EDA、HBM）、实体清单增删、FDPR 与"脚注"规则、对华投资禁令、301/232 关税、行政令、国会立法动向、联合管制协调，以及中方反制措施背景。每期固定包含「当前生效的对华芯片制裁与管制措施总表」，状态列随每周更新。
